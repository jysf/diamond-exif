# SPEC-037: PNG strip: chunk-level metadata removal under StripPolicy, self-verify, rewrite_png fuzz

> **OUTLINE, `cycle: frame`.** This spec exists so its ID is stable and
> siblings can declare `depends_on`. Capture **scope** (Context / Goal /
> Non-Goals) and **dependencies** only: the *approach* is designed just in time
> when this moves to `design`. Do not pre-design it here.

## Context

The writer foundation (DEC-013) strips JPEG and TIFF: pure function, `EditPlan` of whole-range removals and same-length patches, never longer than the input, output re-audited and compared with the input's audit, fail-closed. PNG is the next container: metadata lives in whole chunks (`eXIf`, `iTXt`/`tEXt`/`zTXt`, `iCCP`, `tIME`, bytes after `IEND`), so removal does not disturb the CRCs of the chunks that stay.

## Goal

`strip` of a PNG under every `StripPolicy`: whole-chunk removal by the audit's category of each chunk (DEC-020's keyword table, raw profiles, `tIME`, `iCCP`), a decision on `eXIf` (remove whole, or delete entries in place with the chunk CRC patched, as JPEG does inside an Exif segment), self-verification by re-audit, typed refusals, and a `rewrite_png` fuzz target with a 60 s CI smoke. DEC for the PNG write (DEC-021).

## Non-Goals

- WebP (SPEC-038); the audit and CLI switch-over (SPEC-039: `ContainerKind::strippable()` stays false until then); `set` operations; APNG frame handling; XMP or ICC content editing.

## Notes for the Implementer

Strip must work from the chunk walk, never from the library's lists alone. Carried hostile edges (SPEC-032 verify): a raw-profile chunk can hold GPS that we do not decode, so it is removed or the strip refuses (fail closed), never kept under a policy that removes GPS; `tIME` of any length is a timestamp; empty regions are still metadata for PNG; a nameless length-0 `iCCP` is a walk issue with no located region, so removal by region misses it; text after `IEND` and several `eXIf` chunks must all go. Keep `Preview::strippable()` false until SPEC-039 so no report claims a removal early.
