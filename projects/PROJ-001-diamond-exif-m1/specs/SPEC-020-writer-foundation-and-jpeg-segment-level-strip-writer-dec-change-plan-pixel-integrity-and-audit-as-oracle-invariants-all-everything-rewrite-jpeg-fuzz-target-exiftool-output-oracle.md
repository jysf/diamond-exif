# SPEC-020: Writer foundation and JPEG segment-level strip: writer DEC, change plan, pixel-integrity and audit-as-oracle invariants, `All`/`Everything`, `rewrite_jpeg` fuzz target, ExifTool output oracle

> **OUTLINE — `cycle: frame`.** This spec exists so its ID is stable and
> siblings can declare `depends_on: [SPEC-020]`. Capture **scope** (Context /
> Goal / Non-Goals) and **dependencies** only — the *approach* is designed
> just-in-time when this moves to `design`. Do not pre-design it here.

## Context

The first writer spec. The design decision record for the writer is written at its design (change plan, pixel integrity, scrub, no growth, no relocation, Multi-Picture as a unit, defaults for unknown segments and trailers; SPIKE-001 is the evidence). The broad presets (`All`, `Everything`) need only whole-segment removal, which needs no offset arithmetic, so they come first: the safest place to prove the invariants (pixel bytes unchanged, the output's audit shows none of the removed categories, ExifTool agrees) before any offset is rewritten.

## Goal

`strip(bytes, StripPolicy)` and `sanitize` for JPEG by whole-segment removal for `All` and `Everything`, a change-plan type, the writer DEC, the invariants as tests and fuzz guards, a `rewrite_jpeg` fuzz target, and an ExifTool output oracle with red-proofs.

## Non-Goals

- In-IFD entry deletion (next spec); TIFF/DNG; any `set` operation; a write CLI
