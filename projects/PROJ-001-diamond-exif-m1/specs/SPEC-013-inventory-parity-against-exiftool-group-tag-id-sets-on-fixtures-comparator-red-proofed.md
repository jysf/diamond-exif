# SPEC-013: Inventory parity against ExifTool: group + tag-id sets on fixtures, comparator red-proofed

> **OUTLINE — `cycle: frame`.** This spec exists so its ID is stable and
> siblings can declare `depends_on: [SPEC-013]`. Capture **scope** (Context /
> Goal / Non-Goals) and **dependencies** only — the *approach* is designed
> just-in-time when this moves to `design`. Do not pre-design it here.

## Context

The audit model must claim an inventory, and an inventory claim is only worth something if the reference tool agrees with it. SPEC-005/008/011 built the comparator, records and red-proof apparatus for tag *values*; this spec points the same discipline at the *set* of tags the audit reports: group and tag id per fixture, for TIFF and for JPEG-wrapped TIFF.

## Goal

Committed ExifTool records of the tag listing (group and id) for the existing fixtures, a comparator for the sets, live and replay tests with zero unexplained differences, and red-proofs (control first) showing a dropped or invented tag is named. Every difference is a recorded divergence with command, version and measured output.

## Non-Goals

- Value comparison (already done for the 20 selectors); XMP/ICC/IPTC contents
- Changing the audit model, except to fix a bug the oracle finds (reported, then decided)
- New hostile shapes without first probing them alone under the ExifTool time limit
